# ЛПР-1 — гусеничный робототехнический комплекс для посадки семян деревьев

**ЛПР-1** — экспериментальный наземный робот на двухгусеничной платформе с дистанционным управлением и автоматизированным механизмом формирования лунки и подачи семян.

Проект разработан для кейса № 3 «СтудентыПро»: автоматизация посадки семян деревьев с заданным интервалом между посадками. Репозиторий содержит программное обеспечение Raspberry Pi, исходники прошивки контроллера STM32, диагностические скрипты и технические материалы.

> **Статус:** экспериментальный образец. Программная реализация отдельных функций не равнозначна подтверждению их надёжности в полевых испытаниях. Автономное движение по маршруту и автоматический обход препятствий пока не реализованы.

## Состав комплекса

| Подсистема | Оборудование / реализация |
|---|---|
| Центральный вычислитель | Raspberry Pi 3B+, Python |
| Шасси | Две гусеницы, независимые электроприводы |

## Управление с пульта

В конфигурации [`rc_drive.py`](raspberry-pi/rc_drive.py) предусмотрено:

- **SwA / CH5** — разрешение работы (ARM); при отключении — остановка.
- **SwD / CH7** — переключение между ходовой частью и манипулятором.
- **SwC / CH10** — режим камеры, возврат рабочего органа к верхней точке и запуск **одного** посадочного цикла при переключении в положение посадки.
- **VrB / CH6** — регулирование предельной скорости движения либо скорости манипулятора.

Перед движением требуется разрешение ARM и нейтральное положение стиков. Посев начинается только при остановленной платформе, нейтральных стиках и выбранном режиме ходовой части. Во время посадки движение заблокировано.

## Последовательность одной посадки

```text
Команда оператора
       ↓
Проверки разрешения, режима и остановки
       ↓
При необходимости — поиск верхнего положения
       ↓
Опускание «клюва» в грунт
       ↓
Контроль хода и токов двух приводов
       ↓
Пауза → набор семени челноком → сброс семени
       ↓
Частичный подъём → пауза → возврат к верхнему положению
       ↓
Завершение цикла и разблокировка движения
```

Алгоритм реализован в [`seeder.py`](raspberry-pi/seeder.py), дозатор — в [`shuttle.py`](raspberry-pi/shuttle.py). Программные настройки предусматривают ориентировочную длительность цикла **около 5 секунд**; фактическое время зависит от исходного положения механизма, нагрузки и защитных условий. Токовые пороги требуют калибровки на грунте. При недоступности INA219 предусмотрен явно регистрируемый режим движения по времени.

## Контроль состояния и безопасность

1. Потеря корректных кадров i-BUS более **0,3 с** инициирует безопасную остановку.
2. Драйвер ходовой части останавливает команду при прекращении обновления примерно на **0,3 с**.
3. В прошивке STM32 предусмотрен собственный таймаут отсутствия команд около **0,8 с**.
4. Во время посадки движение гусениц заблокировано; посадка и управление манипулятором разделены по режимам.
5. Для обнаружения нагрузки и возможного заклинивания вертикального органа используются INA219.
6. На самом пульте требуется настроить **Failsafe**: ARM в состояние «выключено», стики — в нейтраль.

**Предупреждение:** эти пункты описывают предусмотренную логику. Результаты проверки защит на физическом роботе необходимо фиксировать в отдельных протоколах.

## GPS и регистрация посадок

[`gps_log.py`](raspberry-pi/gps_log.py) работает отдельно от управления движением. Приёмник NEO-M8N передаёт NMEA-данные; журнал включает:

- `posadka.csv` — события посадки с координатами и информацией о качестве решения;
- `trek.csv` — маршрут движения;
- `nmea.log` — исходные сообщения GPS для последующей проверки.

Файлы записываются на подключённый USB-накопитель; при временном отсутствии накопителя данные буферизуются в оперативной памяти в пределах установленных ограничений. При потере питания несохранённые данные могут быть потеряны. Наличие GPS **не означает**, что робот способен самостоятельно двигаться по координатам или выдерживать фиксированный интервал без участия оператора.

## Проверка кода

Программная проверка контрольной копии от 24.10.2026: синтаксис Python успешно проверен; **35 из 35 тестов** в `test_modules.py` пройдены; тесты GPS-журналирования и экспорта в `test_gps_log.py` также завершились успешно. Проверки выполнены без физических приводов — [подробности и ограничения](docs/TESTING.md).

Для ознакомления проверяющим **не требуется физический робот**. Начните с `rc_drive.py`, затем изучите `seeder.py`, `shuttle.py`, `hoverboard.py` и `gps_log.py`.

Безопасная проверка синтаксиса:

```bash
python3 -m compileall raspberry-pi/
```

Эта команда не приводит механизмы в движение. Не запускайте `rc_drive.py`, `seeder.py cycle`, `spin_test.py` и другие команды управления приводами вне подготовленного стенда. Подробнее — в [TESTING.md](docs/TESTING.md).

## Примечания к исходникам

- `raspberry-pi/` — код управления, тесты и диагностические скрипты команды.
- `firmware/source/` — проект прошивки контроллера STM32, включая сторонние библиотеки и исходные лицензии.
- `tools/windows/` — вспомогательные скрипты для обслуживания с Windows.
- `docs/` — технические материалы и инструкции.

Репозиторий предназначен для экспертной оценки программной архитектуры и инженерных решений. Не следует считать его универсальным установочным комплектом для оборудования иной конфигурации.
