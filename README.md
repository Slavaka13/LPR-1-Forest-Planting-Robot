# ЛПР-1 — гусеничный робот для посадки семян деревьев

Экспериментальный робототехнический комплекс для дистанционного управления гусеничным шасси и автоматизированного посадочного цикла.

## Для проверяющих

- [Архитектура](docs/ARCHITECTURE.md) — Raspberry Pi, STM32, датчики и приводы.
- [Программные модули](docs/SOFTWARE.md) — карта исходного кода.
- [Испытания](docs/TESTING.md) — проверка функций и ограничения безопасности.
- [Установка](docs/INSTALLATION.md) — обзор условий запуска.

**Внимание:** репозиторий создаётся поэтапно. Исходные файлы и подробная схема будут добавлены из контрольного архива команды. Не следует считать отсутствие файлов признаком отсутствия реализации.

## О проекте

- Центральный компьютер Raspberry Pi 3B+, управляющая программа Python `rc_drive.py`.
- Радиоуправление FlySky FS-i6 / FS-X6B по i-BUS.
- STM32 с FOC-прошивкой управляет двумя приводами гусеничного шасси.
- Посадочный механизм: два MG996R 360°, дозатор MG90S, контроллер PCA9685, датчики INA219.
- GPS NEO-M8N, камеры и дополнительный манипулятор.

## Основные реализованные функции

1. Дистанционное управление движением.
2. Автоматизированный посадочный цикл по команде оператора.
3. Блокировка движения во время посадки и защита при потере радиосигнала.
4. Программная регистрация GPS-точек посадки.

## Ограничения

Автономная навигация, автоматический объезд препятствий и выбор места посадки требуют доработки. Расчётное время рабочего цикла около 5 секунд не является подтверждённой полевой производительностью.

## Безопасность

Не запускайте команды управления приводами на неподготовленном стенде. Фактическое срабатывание защит должно подтверждаться испытаниями.
