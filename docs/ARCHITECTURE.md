# Архитектура ЛПР-1

## Контроллеры и связь

| Подсистема | Реализация |
|---|---|
| Центральное управление | Raspberry Pi 3B+, Python, `rc_drive.py` |
| Радиоуправление | FlySky FS-i6 → FS-X6B → i-BUS → USB |
| Ходовая часть | UART 115200 бит/с → STM32 с FOC-прошивкой → два привода |
| Посадочный механизм | PCA9685 0x40, два MG996R 360°, MG90S |
| Контроль токов | INA219 0x41 и 0x44 |
| Манипулятор | PCA9685 0x42 |
| GPS | NEO-M8N через USB |
| Камера посева | Logitech C270 |

Главная программа обновляет управление приблизительно каждые 20 мс (50 Гц). Посадочный механизм выполняет последовательность «опускание рабочего органа — подача семени — подъём».

## Безопасность

В программе предусмотрена остановка при отсутствии актуальных кадров радиоуправления более 0,3 с. Драйвер передачи команд ходовой части и прошивка STM32 имеют отдельные таймауты. Во время посадки движение гусениц блокируется.

## Ограничения

Нет подтверждённой полностью автономной навигации, автоматического обхода препятствий, прямого датчика глубины лунки. Работоспособность на грунте требует протоколов испытаний.
