# Аппаратные интерфейсы и карта оборудования

Этот документ описывает конфигурацию **конкретного прототипа ЛПР-1**, а не универсальную схему подключения. Перед включением сверяйте с [электрической схемой](electrical-schematic.pdf) и маркировкой проводов.

## Вычислительная система

- Raspberry Pi 3B+ под Linux, основной процесс `rc_drive.py`, запуск через `rc-drive.service`.
- STM32 на плате гироскутера: отдельная FOC-прошивка управляет двумя приводами гусениц.
- Радиоканал FlySky FS-i6 → FS-X6B → i-BUS → HW-597 → последовательный интерфейс Pi.
- UART `/dev/serial0` на Pi, скорость 115200 бод — связь с платой STM32. В `hoverboard.py` описаны линии TX/RX для **левого разъёма** конкретной платы и запрет подключения её 15 В к GPIO Raspberry Pi.

## Адреса I²C и назначения

| Адрес | Устройство | Функции |
|---|---|---|
| `0x40` | PCA9685 №1 | Сервы «клюва» (каналы 0, 1), челнок (канал 2), переключатель камер (канал 8) |
| `0x41` | INA219 №1 | Ток левого сервопривода «клюва» |
| `0x42` | PCA9685 №2 | Манипулятор: поворот 0, плечо 1, предплечье 2, захват 4 |
| `0x44` | INA219 №2 | Ток правого сервопривода «клюва» |

Адреса и назначение подтверждаются комментариями и конфигурацией исходников. Подменять адреса «для удобства» нельзя без соответствующей перенастройки или перепайки.

## Питание

Управляющая часть Pi и исполнительные механизмы могут иметь разные источники питания. В исходниках явно оговорён общий источник 6 В для посадочного механизма и манипулятора; их одновременная работа программно исключена. Мощность, защитные автоматы/предохранители, токовые ограничения и схема заземления/общего GND требуют проверки по реальной электрической схеме и измерениям.

## Приводы и измерения

Два MG996R 360° не дают абсолютного обратного сигнала положения; их нейтральные импульсы могут различаться и должны калиброваться. Челнок использует MG90S с угловым позиционированием. INA219 измеряют ток и напряжение, но не заменяют датчик глубины.

## GPS и видео

GPS NEO-M8N по USB-UART (в `gps_log.py` NMEA 9600 бод); Logitech C270 для регистрационных роликов. Выбор FPV-камер зависит от отдельного модуля W8010S. Данные GPS сохраняются на USB-носитель с заданной меткой/путём монтирования; это часть текущей конфигурации, а не универсальное ограничение Linux.

## Ограничения и риски интеграции

1. Условные пути `/dev/serial/by-id/` отличаются для каждого USB-адаптера.
2. Raspberry Pi 3B+ использует логические уровни GPIO 3,3 В; подача 5/6/15 В непосредственно на GPIO может вывести плату из строя.
3. Для нескольких устройств I²C требуется проверка адресных конфликтов и общего питания.
4. Токовые пороги посадочного механизма пока не откалиброваны для разных грунтов.
5. Подключение моторов и автономные эксперименты допускаются только с аппаратным аварийным отключением питания.
