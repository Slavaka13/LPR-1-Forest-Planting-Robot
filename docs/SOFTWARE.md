# Карта программных модулей

| Файл | Назначение |
|---|---|
| `raspberry-pi/rc_drive.py` | Основной цикл и режимы управления |
| `raspberry-pi/ibus.py` | Чтение i-BUS |
| `raspberry-pi/hoverboard.py` | Обмен со STM32 |
| `raspberry-pi/hw.py` | Работа с I²C, PCA9685 и INA219 |
| `raspberry-pi/seeder.py` | Заглубление, сброс семени и подъём |
| `raspberry-pi/shuttle.py` | Дозирующий механизм |
| `raspberry-pi/arm.py` | Роботизированный манипулятор |
| `raspberry-pi/gps_log.py` | Запись координат и точек посадки |
| `raspberry-pi/seed_cam.py` | Видеорегистрация сброса семени |
| `raspberry-pi/camsel.py` | Переключение камер |

Точка входа штатной системы: `rc_drive.py`. Автозапуск организован через `rc-drive.service`.

Исходники могут включать стороннюю FOC-прошивку, поэтому необходимо сохранить её лицензии и авторские уведомления.

**Состояние загрузки:** исходные файлы Raspberry Pi и прошивки STM32 размещены в закрытом репозитории. Проверка выполнения на физическом роботе должна проводиться отдельно.
