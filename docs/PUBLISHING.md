# Публикация полного исходного комплекта

Документация создана в закрытом GitHub-репозитории. Для импорта оригинального программного кода ЛПР-1 подготовлен отдельный проверенный ZIP-пакет `LPR-1-GitHub-Ready.zip`, выдаваемый команде проекта.

## Перенос с Windows

1. Установите Git for Windows и выполните авторизацию GitHub для `Slavaka13`.
2. Распакуйте ZIP полностью в отдельную папку на локальном компьютере.
3. Откройте PowerShell в распакованной папке и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\PUBLISH_TO_GITHUB.ps1
```

4. Ознакомьтесь со списком добавленных файлов и подтвердите публикацию словом `YES`.
5. Проверьте содержимое каталогов `raspberry-pi/`, `firmware/source/`, `tools/` и `docs/` в закрытом репозитории.

Скрипт клонирует репозиторий, копирует оригинальные исходные файлы, сохраняет размещённую онлайн документацию и публикует изменения одним коммитом. При отказе от подтверждения ничего не публикует.

**Важно:** перед запуском проверьте список файлов и отсутствие секретов, персональных GPS-журналов и информации, не предназначенной для комиссии. Конфигурация робота содержит движения механических приводов: публикация не равнозначна разрешению запускать их на неподготовленном стенде.

## Источник данных

Контрольный исходный архив проекта «ЛПР-1.zip», состояние на 23 октября 2026 г. Ключевые программы оставлены без исправления рабочих алгоритмов.

## Проверка

Для просмотра исходников не требуется их запуск. Синтаксис Python можно проверить отдельно: `python3 -m compileall raspberry-pi/`. Настройку железа и автозапуск службы выполнять только на подготовленной системе.
