# Методика проверки

## Проверки без физического робота

1. Проверить структуру проекта и назначения модулей.
2. Проверить синтаксис Python: `python3 -m compileall raspberry-pi/`.
3. Изучить `test_modules.py` и `test_gps_log.py`; запускать только после проверки их действий.
4. Проверить исходники прошивки и их лицензионные уведомления.

## Испытания на стенде

- Проверка радиоканалов и нейтрального положения органов управления.
- Проверка потери радиосигнала и таймаутов ходовой части.
- Контроль работы PCA9685 и INA219.
- Не менее 10 измерений фактической глубины лунки.
- 20–30 циклов подачи семени для оценки успешности дозирования.
- Измерение полного времени операции, включая переезд.

**Безопасность:** команды вращения двигателей и движения рабочего органа выполнять только на подготовленном стенде, при доступном аварийном обесточивании и отсутствии людей в рабочей зоне. Не блокировать механизмы руками.

Рассчитанные по коду ≈5 с посадочного цикла и 720 операций/ч без переездов **не являются результатами полевых испытаний**.
