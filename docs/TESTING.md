# Испытания и проверка ЛПР-1

В этом документе **различаются программная проверка без оборудования и натурные испытания**. Запрещается трактовать успешное выполнение программных тестов как подтверждение надёжности механического робота.

## 1. Программные проверки — выполнено 24.10.2026

На предоставленной контрольной копии исходников ЛПР-1 выполнены команды:

```bash
cd raspberry-pi
python3 -m compileall -q .
python3 test_modules.py
python3 test_gps_log.py
```

| Проверка | Результат | Значение |
|---|---|---|
| `compileall` | Код возврата 0 | Файлы Python синтаксически корректны |
| `test_modules.py` | **35 из 35** проверок успешно | Программные сценарии управления, посадки, ошибок и периферии на фиктивном оборудовании |
| `test_gps_log.py` | **«ИТОГ: всё в порядке»** | Обработка NMEA и экспорт данных, включая GPX, KML, GeoJSON |

Тесты выполнены в локальной среде Python на копии файлов проекта, **без подключения двигателя, сервоприводов, радиопульта или GPS-приёмника**. Эти тесты не проверяют физическое положение рабочего органа, реальную скорость шасси, безопасность питания и точность позиционирования.

## 2. Как повторить программные тесты

Откройте корень репозитория и выполните:

```bash
cd raspberry-pi
python3 -m compileall -q .
python3 test_modules.py
python3 test_gps_log.py
```

Если среда отличается от тестовой, часть зависимостей может потребоваться установить. Программные тесты ориентированы на имитацию недоступного оборудования и не должны запускать физические приводы, но перед исполнением на Raspberry Pi с подключённым роботом необходимо повторно проверить импорты и сценарии.

## 4. Методика натурных испытаний (пока без результатов)

**А. Шасси:** движение вперёд/назад, поворот, время остановки при потере связи, преодоление неровностей, устойчивость при посадке.

**Б. Посадка:** не менее 10 повторений, для каждого измерить фактическую глубину и время цикла. Рассчитать среднее, размах и отклонение от заданного значения.

**В. Дозирование:** 20–30 попыток; зафиксировать долю корректных порций семян, пропуски и двойные подачи.

**Г. Защита:** безопасно проверить отключение ARM, исчезновение i-BUS, зависание связи, отказ I²C и затруднение движения рабочего органа. Не имитировать клин руками.

**Д. Производительность:** учитывать и посадку, и переезды, и пополнение семян, и остановки на обслуживание. Значение «720 операций/ч» — математический предел при пятисекундном цикле без движения и пауз, а не фактический показатель комплекса.

## 6. Безопасность

Испытания движения проводить только на подготовленном стенде, с доступным физическим аварийным обесточиванием. Не запускать команды диагностики приводов на неподготовленном роботе, не препятствовать «клюву» руками, не работать одновременно с двумя независимыми программами управления одним устройством.
