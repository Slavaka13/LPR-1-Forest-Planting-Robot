# Сторонние программные компоненты и авторство

Репозиторий содержит не только собственные управляющие модули ЛПР-1, но и исходные библиотеки и проект прошивки контроллера.

## Выделение частей

| Путь | Происхождение / назначение |
|---|---|
| `raspberry-pi/` | Управляющие модули, диагностические и тестовые программы команды ЛПР-1 |
| `firmware/source/` | Исходное дерево проекта hoverboard FOC, используемого для STM32 и адаптированного под ходовую часть |
| `firmware/source/Drivers/CMSIS/` | ARM CMSIS и примеры DSP |
| `firmware/source/Drivers/STM32F1xx_HAL_Driver/` | STM32 HAL/LL |
| `firmware/source/Arduino/` | Пример сторонней программы последовательного обмена |
| `firmware/source/README.md` | Документация проекта прошивки |
| `firmware/source/LICENSE` | Условия использования исходников прошивки |

## Принцип корректного описания проекта

- Работа команды включает инженерную интеграцию, настройку, компоновку узлов, программирование управления Raspberry Pi и адаптацию контроллера.
- Не следует выдавать HAL, CMSIS и математическое ядро существующего FOC-контроллера за созданные командой с нуля.
- Сохранение лицензий, авторских уведомлений и условий повторного распространения обязательно даже в закрытом репозитории.
- Перед переводом репозитория в публичный режим дополнительно проверить происхождение стороннего кода и наличие разрешения на распространение каждого компонента.

Этот документ не является юридическим заключением о лицензиях. Окончательное решение по распространению основывается на текстах лицензий в конкретных папках.
