# Инструкция по развёртыванию

Инструкция предназначена для технических специалистов. Прежде чем включать двигатели, проверьте схему питания и механическую безопасность.

## Оборудование

- Raspberry Pi 3B+, Python 3 и Linux.
- STM32-плата с совместимой FOC-прошивкой.
- Приёмник FS-X6B через i-BUS и USB-адаптер.
- PCA9685 0x40/0x42, INA219 0x41/0x44.
- При необходимости NEO-M8N, USB-камера и внешний накопитель.

## Запуск

Основная программа `raspberry-pi/rc_drive.py` рассчитана на конкретную аппаратную конфигурацию; штатный запуск выполняется службой `rc-drive.service`.

Прежде чем запускать сервис, проверьте распиновку, питание, последовательные устройства, параметры I²C, конфигурацию портов, совместимость зависимостей и настройки защит.

На обычном ПК допустима только статическая проверка и заведомо безопасные программные тесты.
