# История изменений

- Обновлена главная страница README с навигацией по исходникам и технической архитектурой.
- Загружен исходный комплект Raspberry Pi, проекта прошивки STM32 и PDF-схемы.
- Добавлены подробные документы `FILE-CATALOG.md`, `CONTROL.md`, `PLANTING.md`, `HARDWARE-INTERFACES.md`, `GPS-AND-VIDEO.md`.

- Иллюстрации общего вида, посадочного механизма и компоновки пока намеренно не добавлены.
